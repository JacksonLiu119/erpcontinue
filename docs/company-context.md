# 公司別與來源資料庫隔離

介面上方的「公司」與「資料庫」是兩個不同概念，但目前採用一對一綁定：一個客戶公司的來源資料庫對應一個公司上下文。這樣未來匯入另一家公司資料庫時，可以新增一筆 `erp_data_sources` 設定，不會把兩家公司資料放在同一個來源範圍。

## 目前資料流

1. `erp_data_sources` 維護來源資料庫代號、資料庫名稱、租戶、公司與來源系統。
2. `erp_companies` 保存從來源公司資料表匯入的公司名稱、統編與聯絡資料。
3. `/api/company-contexts` 將兩者整理成介面可選的公司清單；若尚未匯入公司主檔，會先顯示來源設定名稱。
4. 前端切換公司時，同步切換 `source_database`，並在每次 API 請求帶入 `X-Company-Id` 與 `X-Source-Database`。
5. API 端驗證公司與來源是否一致；不一致的請求會拒絕，避免誤查或誤寫其他公司的資料。

新增公司資料庫時，請在 `erp_data_sources` 建立新的來源設定，並以來源資料庫的公司主檔匯入 `erp_companies`。原始客戶資料庫保持唯讀，新 ERP 的新增與修改仍只寫入 `inventory_erp`。
